# APD – Laborator
Proiect de laborator pentru disciplina Achiziția și prelucrarea datelor.
Nod de achiziție a temperaturii bazat pe Arduino Uno.
## Autor
Enaru Emanuel - 4LF341
## Hardware
Arduino Uno R3, senzor de temperatură TMP36
## Parametri
- LED_PIN: Pinul digital la care este conectat LED-ul de stare.
- SERIAL_BAUD: Viteza de comunicatie pe portul serial.
Comunicatie seriala la 11520 baud
Comunicatie seriala la 19200 buad
Comunicație serială suportată la 115200 baud (mod rapid) și la 19200 baud (mod compatibil).
